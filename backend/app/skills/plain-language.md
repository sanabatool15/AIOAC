# Plain words

Say it simply. The user is not a data scientist.

| Instead of | Say |
|---|---|
| accuracy, F1 | "about 8 out of 10 predictions were right" |
| train/test split | "tested on data the model had not seen" |
| target column | "the answer column" or "the thing to predict" |
| class imbalance | "far more customers stayed than left" |
| baseline | "a quick free test" |
| inference | "using the model" |

Ask one short question at a time. Do not mention tools, instance types or model names.
