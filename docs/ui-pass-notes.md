# UI pass notes

Cross-lane notes for the UI pass (spec: CODEX_PROMPT_UI_PASS_1). Each lane edits only its own files and leaves notes here.

## Lane 1 (foundations): done

Owned: `frontend/app/globals.css`, `frontend/components/ui/*`, `frontend/lib/utils.ts`, tests in `frontend/unit/ui-*.test.ts`.

### What exists now

- Tokens (`globals.css`): flat violet `brand`, `brand-hover`, `brand-soft/tint/line/edge/ink`; meaning colours `success|warning|danger` each with `-soft` and `-line`; `on-brand`; `scrim`; text `title 24/600`, `section 16/600`, `body 14`, `small 13`, `micro 12` (`text-title` ...); radii sm 6, md 8, lg 12, xl 16 (note: this shifts the Tailwind defaults, so any old `rounded-lg` is now 12px and `rounded-xl` 16px); widths `max-w-chat` (44rem), `max-w-form` (34rem), `max-w-page` (72rem); shadows `shadow-card` (small, neutral), `shadow-popover`, `shadow-drawer`; `field-shell` utility (focus-within ring for the composer); global focus-visible outline; reduced-motion rule.
- Contrast: every text token is at least 4.5:1 on the surfaces it is used on, enforced by `unit/ui-tokens.test.ts`. Changed values: `muted` #5b6779, `pending` = muted, `success` #15803d, `danger` #b91c1c (darker than before). Do not use `text-brand-light` or similar, they are gone.
- Removed: `brand-light/mid/deep`, `success-light`, `danger-light`, `banner`, `secondary*`, `track*`, `switch-off`, `hold-buffer`, `orb-bg`, `code`, `trace-*`, `detected-*`, `overlay-*`, all `surface-*` utilities, `bg-trace*`, `surface-detected`. Nothing outside `components/ui` used them.
- Components: `Button` (variants primary, outline, ghost, destructive; sizes sm, md, lg, icon; `block` for full width), `LinkButton`, `buttonVariants()` (accepts the old names), `Card` (plain, success, warning, danger, highlight), `Tag` (neutral, brand, success, warning, danger), `StatusChip`, `Modal`, `Tabs`, `PageHeader`, `EstimateNote`, `Stepper`, `EmptyState`, `ErrorState` (retry optional, `title` prop), `Skeleton`, `Input`, `Textarea`, `FieldShell`, `Field` (`hint`, `error`), toast (errors in a `role="alert"` region, dismiss button, 8 s), `ProgressBar` (flat), `Checkbox`.
- `cn()` is configured so `text-title` / `shadow-card` / `max-w-chat` merge correctly with other classes.

### API cheat sheet for the other lanes

```tsx
<Modal open onClose title="Share this result" description="..." role="dialog|alertdialog" footer={<Button>..</Button>}>...</Modal>
// mark the element to focus first with data-autofocus. alertdialog does not close on backdrop click.
<Tabs label="Project" tabs={[{id, label}]} value onValueChange panels={{id: node}} />   // all panels mounted, inactive hidden
<Tabs ...>{activePanelOnly}</Tabs>                                                       // lazy variant
<Stepper steps={[{id, label}]} current={2 /* 0-based */} />                              // "Step 3 of N" under sm
<PageHeader title subtitle actions clampTitle />   // renders the page's one h1
<EstimateNote />                                   // once per screen
<LinkButton href="/x" variant="outline" size="sm" />
<EmptyState icon={FolderOpen} title body action />
<FieldShell><textarea className="w-full bg-transparent outline-none" /></FieldShell>     // composer focus ring
```

### Deprecated compatibility layer (Lane 7 deletes it)

Old names still compile (marked `@deprecated` in the types) and render as the new flat equivalents:

| Old | Now | Where defined |
|---|---|---|
| Card `violet` | `highlight` | `components/ui/card.tsx` (`CARD_ALIAS`) |
| Card `blue`, `peach`, `mint` | `plain` (colour carried position, not meaning) | same |
| Card `green` / `red` / `amber` | `success` / `danger` / `warning` | same |
| Tag `muted`, `dashed` | `neutral` (use `warning` or `danger` for failures) | `tag.tsx` (`TAG_ALIAS`) |
| Button variant `icon` | `ghost` | `button.tsx` |
| Button size `default` | `sm`; `action` | `lg` | same |
| Button size `lg` | no longer full width: add `block` | same |
| `buttonVariants({size:"action"})` | still works; prefer `LinkButton` | same |
| ProgressBar `track` | ignored | `progress-bar.tsx` |
| utilities `bg-brand-gradient`, `bg-brand-gradient-diag`, `bg-success-gradient`, `bg-danger-gradient` | flat colour | `globals.css` |
| utility `bg-overlay` | `var(--scrim)` (use `Modal`) | `globals.css` |
| shadows `shadow-card-tight`, `shadow-composer`, `shadow-glow`, `shadow-btn-*`, `shadow-menu` | small neutral shadow or none | `globals.css` |
| EmptyState `icon={<span>·</span>}` | still renders; pass a lucide component | `state.tsx` |

Behaviour changes callers may notice: omitted Button `size` is now `md` (was a compact size); `ErrorState`/`EmptyState` unchanged otherwise; `Input` radius and padding follow the new scale.
